# 声稿 / Voice Studio

声稿是以本人声线为核心的本地内容制作工作台。当前产品目标是“文案 → 可试听、可局部修改的配音 → 虚拟讲解视频”，继续提供纯字幕讲解模式。虚拟讲解员使用可替换的原创角色，首个角色为卡通小机器人 `studio-bot`，无需提供照片或短视频，也不仿制本人的脸。

0.2 的声音生产和字幕视频能力已有独立验证记录；0.3 虚拟讲解员已完成本轮独立机器检查和横竖屏实渲染，角色观感仍需观看确认，不沿用字幕视频的通过结论。

## 产品范围

| 能力 | 预期行为 |
| --- | --- |
| 文案导入 | 支持直接输入及导入 UTF-8 TXT、Markdown；Markdown 作为文本处理，不承诺完整排版渲染。 |
| 整稿分段 | 将整稿拆为有序段落，保留原文，允许检查及调整分段结果。 |
| 单段编辑 | 修改指定段落；明确标记旧音频与当前文本是否一致。 |
| 生成与重生成 | 支持整稿生成、单段生成及单段重生成；局部修改无需强制重做整稿。 |
| 异步任务 | 显示排队、运行、完成、失败及取消状态；进度按实际阶段或已完成段数呈现。 |
| 项目与版本 | 持久保存文案、段序、生成参数、任务状态及音频版本；重启后可继续查看项目。 |
| 既有声线 | 引用已经跑通的本地模型、参考录音及参考文本，并提供既有样音供对照试听。 |
| 导出 | 导出整稿 WAV、MP3、段级 SRT 及包含工程信息的 ZIP；MP3 使用本机 ffmpeg。 |
| 生产工具 | 声线档案、发音词典、批量队列、工程恢复和需确认后采用的文案建议复用同一项目及版本。 |
| 视频模式 | 界面默认选择虚拟讲解员 `virtual_host`，可切换纯字幕 `captions`；横屏、竖屏均使用已经导出的配音和段级时间轴。 |
| 虚拟角色（0.3） | 本地生成原创小机器人 SVG；用音频能量驱动嘴部开合，配合眨眼与轻微动作，保留角色和动画工程供编辑与替换。 |

## 主要流程

1. 新建或打开项目，输入或导入文案。
2. 检查分段，编辑需要调整的段落。
3. 提交生成任务，查看进度，必要时取消。
4. 逐段试听；对指定段落修改并重生成，选择要用于成品的有效版本。
5. 生成整稿音频，导出音频、字幕或工程包。
6. 选择虚拟讲解员或字幕讲解，生成 MP4 并保存包含素材的可编辑视频工程。

生成结果必须与其输入文本、参数和声音配置关联。段落文本改变后，旧音频仍可保留为历史，但不得悄然作为当前文本的已完成结果。工程包应包含文本、段落顺序、配置、版本信息及可导出的成品；默认不打包外部模型、参考录音、环境依赖或缓存。

## 默认边界

- 默认在本机处理，不上传文案、参考录音或生成音频。未来新增远程能力时，应明确说明目的、目标服务和传输内容，由用户主动启用。
- 虚拟讲解员复用本人声线，形象是原创卡通角色；真人照片或短视频驱动路线已取消，不列入待补材料或后续口型目标。
- 嘴部动作根据音频能量开合，眨眼与轻动用于增加角色表现，不宣称精细音素口型、情绪识别或实时对话。
- 既有约 14 秒中文样音曾被用户接受，只能代表那段文本的验收；不能据此认定新文案的声线、自然度及长稿表现已被接受。
- 新文案可先完成机器流程验收，包括任务完成、文件可解码、段序和导出一致性等；主观声线、发音及听感须由用户试听确认。
- 段级 SRT 以已选配音版本及其实际时长为依据，属于每段一个字幕条目的基础能力，不等同于字级强制对齐。

## 验收依据

第一版应验证导入、分段、编辑、生成、取消、重启后读取、局部重生成及四类导出能够形成完整流程。取消后不应继续把取消任务标记为成功；失败应保留可理解的原因。导出前应识别缺失、失效或仍在生成的段落，避免悄然生成不完整成品。

机器检查记录与用户听感验收应分开保存。本文不预先宣称任何检查已经通过。

0.3 已验证模式与已有项目兼容、横竖屏角色及字幕无溢出、静音时嘴部合上、MP4使用完整原音频，以及工程内SVG和动作数据可编辑。角色外观及动作观感由用户观看确认；渲染成功不等于角色效果已被接受。字级强制对齐、实时对话及几分钟成片仍需独立验收。

## 材料与后续确认

| 类别 | 当前安排 |
| --- | --- |
| 当前所需材料 | 已有本地模型、运行环境、参考录音与样音，配合本地原创机器人即可制作；不需要补照片、短视频或真人形象素材。 |
| 长稿听感 | 在具备可播放结果后，请用户试听具有代表性的较长文案；这是质量确认，不是搭建前置条件。 |
| 更多录音 | 可选；用于以后探索声音一致性与表现改善，不保证增加录音就必然提高效果。 |
| 文案建议 | 当前本机模型建议需逐句核对后采用；更强模型与文风样例为可选改善材料。 |
| 虚拟角色偏好 | 先提供原创机器人供观看；后续可调整或替换 SVG 角色，不阻碍当前实现。 |
